# Foodiya pages

Use the existing PageScreen or PageFrame composition. Read the
[page contract and native geometry](references/page-guide.md) before changing
header clearance, safe areas, keyboard behavior or touch shielding.

Follow the [implementation pattern](../foodiya-implementation/SKILL.md) and
[mobile UI requirements](../expo-mobile-ui-only/SKILL.md). Keep the page source
in [src/components/ui/page/](../../../src/components/ui/page/); feature workflows
stay with their feature. The guide owns page-specific rules and verification.
